# Fase 06 — Frontend

Aplicación React + TypeScript + Vite. Incluye login bearer, sidebar, diseño responsive, estados de error/vacío y vistas conectadas de dashboard, clientes, productos, ventas e inventario.

Las vistas de clientes y productos crean registros básicos. Ventas permite armar una transacción, confirmar pago, consultar historial y anular con motivo. Inventario consulta existencias y permite ajustes con razón.

## Verificación

`npm run build` compila TypeScript y produce el bundle de producción en `frontend/dist`.
